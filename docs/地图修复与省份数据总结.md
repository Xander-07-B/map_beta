# 地图修复与省份数据替换总结

- 时间：2026-11-17 ～ 2026-11-18
- 范围：矢量世界地图渲染、省份数据管线、弃用清理、台港澳配色
- 涉及提交：`fa18713`（数据替换、渲染修复、清理）、`88341d9`（台港澳配色）

---

## 一、问题背景

项目是一个单机网页版《钢铁雄心4》原型，使用原生 JS + Canvas 2D 绘制 Natural Earth 矢量世界地图，数据由 TopoJSON 分层提供（国界层 + 省份 l0/l1 两档）。此前存在三个明显问题：

1. 地图缩放到最大时，部分国家会“消失”；
2. 最大缩放下出现横贯整张地图的黑色假线；
3. 很多国家没有省级行政区，只有一块纯色，且没有被省界覆盖。

---

## 二、修复内容

### 1. 最大缩放时部分国家“消失”

**根因**：Natural Earth 10m admin-1 只覆盖部分国家（约 157/234）。旧渲染在省份 LOD 只绘制省份填充，没有省份数据的国家（瑞士、台湾等 80 多个）就没有任何填充，露出海洋色。

**修改**（`js/map.js` 的 `draw()`）：两个省份 LOD 分支在绘制省份填充之前，先调用 `drawCountryFills(ctx)` 铺一层国家底色兜底，再叠加省份填充、省界、国界。

```js
this.drawCountryFills(ctx);
this.drawProvinceFills(ctx, 'l0', this.layers.provL0);
this.drawProvinceBorders(ctx, 'provL0');
this.drawCountryBorders(ctx);
```

**效果**：所有国家在任何缩放层级都有颜色，不再露出海洋色。

### 2. 最大缩放时的横贯全图假线

**根因**：经度数值因浮点误差略大于 180° 的点（如瓦朗格尔岛 71°N、汤加/斐济），经 `d3.geoMercator` 投影后被折到地图另一端，坐标从 x≈3628 跳到 x≈468，产生约 3158 世界单位的水平线段，横贯整张地图。

**修改**（`js/map.js`）：

- `buildMeshTiles()`：跨越日期变更线的线段（`Math.abs(bx - ax) > 世界宽度 / 2`）直接丢弃；
- `buildBorderIndex()`：同样条件下 `moveTo` 断开子路径，而不是 `lineTo` 连线。

**效果**：海岸线与国界不再出现横贯全图的假线，两端在地图左右边缘自然断开。

### 3. 省份数据不完整 → 全量重建

**根因**：仓库里其实已有完整的 Natural Earth 10m admin-1 数据（`data/ne_10m_admin_1_states_provinces.geojson`，40.7 MB，4596 个要素，覆盖 251 个 adm0_a3）。旧管线按 `scalerank <= 8` 过滤，只保留 3382 个，丢掉了 1214 个（rank 9：506，rank 10：698，rank 11：10）——瑞士、台湾、乌干达等国家的省份正好都在被丢掉的档位。

**新管线**：不再按 `scalerank` 过滤，只排除南极洲（`adm0_a3 != 'ATA'`，与国界层一致）。

新增 `scripts/build-provinces.mjs`，一条命令重建两档省份：

```js
build(30, "data/provinces.l1.topo.json", 300000);  // 30% 简化，量化 300000
build(8,  "data/provinces.l0.topo.json", 110000);  // 8% 简化，量化 110000
```

构建后剥离 TopoJSON 里的 `properties`（否则文件会膨胀到 14 MB）。名称、归属、bbox 由 `scripts/build-index.mjs` 用 `ne_id` 从原始 GeoJSON 关联生成。

**产物**：

| 文件 | 要素数 | 顶点数 | 大小 |
|---|---:|---:|---:|
| `data/provinces.l1.topo.json` | 4594 | 271,258 | 3.01 MB |
| `data/provinces.l0.topo.json` | 4594 | 91,704 | 1.29 MB |
| `data/index.json` | 4594 条元数据 / 250 个归属国 | — | 1.31 MB |

**覆盖情况**：国界层 241 个几何 id 全部有对应省份（缺失列表为空）。行政区划数量对比：德国 16、美国 51、英国 232、苏联 86、日本 47、法国 101、意大利 110、中国 32、西班牙 52、印度 36、巴西 27、澳大利亚 11。

**验证**：

- 页面加载约 1.34–1.37 s，无 page error、无 404；
- 截图确认瑞士 26 个州（中文名）、台湾各县市、乌干达各区均有真实边界；
- 点击日内瓦能选中「日內瓦州」（id 1159307651）；
- 宣战后的战线正常绘制（边界索引 333 个键）；
- 各 LOD 档位截图无日期变更线伪线段。

**已知限制**：图瓦卢、马绍尔这类环礁在最大缩放下仍只有几个像素，属于源数据分辨率限制，不是渲染问题。

### 4. 弃用文件清理

删除了 4 个已无任何代码或脚本引用的文件：

| 文件 | 原因 |
|---|---|
| `data/provinces.l2.topo.json` | 旧 50m 管线残留（294 要素），分层地图已只用 l0/l1 |
| `data/provinces.json` | 文件已损坏（开头混入 npm 日志），属性已并入 `index.json` |
| `data/stage1.geojson` | 旧管线中间产物，新脚本直接从 10m 源文件构建 |
| `data/ne_50m_admin_1_states_provinces.geojson` | 上述文件的 50m 源数据，已被 10m 版取代 |

保留 `data/ne_50m_admin_0_countries.geojson`：它是当前 `countries.l1.topo.json`（241 个国界几何）的源文件，仓库里没有重建国界层的脚本。

### 5. 台港澳统一配色

**需求**：台湾、香港、澳门的颜色与中国大陆一致。

**修改**（`js/map.js`）：

```js
COLOR_ALIAS: { TWN: 'CHN', HKG: 'CHN', MAC: 'CHN' },

countryColor(iso3) {
    if (!iso3) return this.landColor;
    iso3 = this.COLOR_ALIAS[iso3] || iso3;
    ...
}
```

`provinceColor()` 原本就会回落到 `countryColor()`，所以国家层和省份层同时生效。

**验证**：台湾 21 个县市、香港 18 区、澳门 1 个，共 40 个省份的 `provinceColor()` 全部返回 `#b5954a`，与北京、上海一致；全国层级和省份层级截图均确认同色。

**注意**：这是纯配色改动，数据中的 `adm0_a3` 仍为 TWN/HKG/MAC，游戏归属、军队、人力等玩法数据不变。

## 四、如何重建数据

```bash
npm install                      # 包含 mapshaper devDependency
node scripts/build-provinces.mjs # 重建 provinces.l0/l1.topo.json
node scripts/build-index.mjs     # 重建 index.json（名称/归属/邻接/bbox）
```

注意事项：

- 源文件是 `data/ne_10m_admin_1_states_provinces.geojson`，构建时用 `-filter "adm0_a3 != 'ATA'"` 排除南极洲；
- TopoJSON 在经纬度空间构建，不做投影，运行时由 `d3.geoMercator().fitSize([4096, 2048])` 投影；
- 几何 `id` 使用 `ne_id`，属性已剥离，请勿手动改回保留属性；
- 低档与高档使用不同量化参数，改参后需要同时重建，否则 `index.json` 的 bbox 会对不上。
